# 🦊 Animais Fantásticos

Uma aplicação web desenvolvida para praticar e consolidar conhecimentos em **HTML**, **CSS** e **JavaScript**, explorando conceitos de interatividade, animações, manipulação do DOM e consumo de conteúdo dinâmico em uma interface moderna e responsiva.

> Este projeto foi desenvolvido para fins de estudo e evolução técnica, aplicando boas práticas de desenvolvimento Front-end.

---

## 📖 Sobre o projeto

O **Animais Fantásticos** foi desenvolvido com o objetivo de aprimorar minhas habilidades em **HTML**, **CSS** e **JavaScript**, por meio da implementação de uma aplicação rica em interações e efeitos visuais.

Durante o desenvolvimento, foram aplicados conceitos como:

- Estruturação semântica com HTML5;
- Estilização utilizando CSS3;
- Layout responsivo;
- Manipulação do DOM;
- Eventos e interações do usuário;
- Scroll suave (Smooth Scroll);
- Navegação por abas (Tab Navigation);
- Accordion List;
- Animações utilizando JavaScript;
- Modal;
- Tooltip;
- Dropdown Menu;
- Menu Mobile;
- Funcionamento em horário comercial;
- Consumo de dados utilizando Fetch API;
- Organização modular do código utilizando ES Modules.

Além de consolidar conhecimentos técnicos, este projeto contribuiu para o aprimoramento da organização do código, reutilização de componentes, acessibilidade e experiência do usuário (UI/UX).

## ⚙️ Como executar o projeto

### Clone o repositório

```bash
git clone https://github.com/ralphdosreis/animais-fantasticos.git
```

### Acesse a pasta

```bash
cd animais-fantasticos
```

### Execute o projeto

Como o projeto utiliza apenas HTML, CSS e JavaScript, basta abrir o arquivo:

```text
index.html
```

Ou utilizar um servidor local, como o **Live Server** do VS Code.
